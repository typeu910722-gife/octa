跟它說一聲
它自己去做

像傳訊息給同事。它會開網頁、看畫面、排好時間，做完再跟你說。付錢、刪東西、傳訊息給別人之前，會先問你。

下載 Windows 版（免費）
Windows 10／11 · 安裝檔約 120 MB · 免費

三步就開始

  1. 裝到電腦上按上面的下載。Windows 若說「已保護您的電腦」，按「其他資訊」，再按「仍要執行」。
  2. 接上你已經有的 AIClaude、ChatGPT 都可以。沒有付費方案，就用 Gemini，或電腦上的 Ollama。
  3. 取個名字，直接交代例如：「每半小時看一下 LINE，有新訊息先寫好回覆給我」。它會自己記住這份工作。

它會做什麼

看得到畫面遊戲、後台、分數，它看圖，不靠猜。圖裡沒有的數字，它會直說沒看到。
網頁縮成小卡桌面版平常是一張圓角小卡。打開後是這個機器人的側邊視窗，可以拖、可以拉大小，換到別的機器人不會跟著走。分頁可以關掉。
重要的事先問你付錢、刪除、傳給別人，它會停下來等你點頭。
拖一下就過去訊息、圖片、檔案拖到另一個機器人會先問你，也可以蓋掉原本那則。機器人拖進群組就直接加入。

常見問題

要錢嗎？

OCTA 本身不用錢。AI 用你已經有的方案，或免費的 Gemini、Ollama。

手機也能用嗎？

可以看、可以下指令。真正做事的是那台開著的電腦。電腦關了，事情會先排著，開機再做。

密碼要貼給它嗎？

不要。登入時在打開的瀏覽器裡自己登入，或讓它用你的 Chrome 自動填。它看不到密碼本身。

有 Mac 版嗎？

目前是 Windows。Mac 可以先開網頁版看。
